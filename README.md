# 🛒 OnlineStore

Online grocery store with a shopping cart and checkout, built with vanilla **JavaScript, HTML and CSS**.

🔗 **Live demo:** https://artyom-tyshchenko.github.io/OnlineStore/

## About

Originally a C# console app (product catalog, cart, order checkout, admin panel), rewritten as a browser-based UI to practice DOM manipulation, event handling, and component-style rendering without a framework.

## Features

- Product catalog with add-to-cart buttons
- Cart displayed as a receipt, with the ability to remove items
- Order checkout with order history
- Simple admin panel (hidden login) to add new products to the catalog

## Tech stack

- HTML5
- CSS3
- JavaScript (ES6 classes, no frameworks)

## Run locally

Clone the repo and open `index.html` in your browser — no build step or dependencies required.

```bash
git clone https://github.com/Artyom-Tyshchenko/OnlineStore.git
cd OnlineStore
```

Then just open `index.html` in a browser.
